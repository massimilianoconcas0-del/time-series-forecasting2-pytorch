Ciber Fabbrica is a standalone, intent-driven production ecosystem engineered specifically for Physical Out-of-Distribution (OOD) Machine Learning. Rather than requiring brute-force training cycles or continuous fine-tuning, Ciber Fabbrica synthesizes deployment-ready models directly from structural specifications. The user provides only three variables:
1. Domain Context

*   **Textual OOD (LLM Infrastructure):** Delivers deterministic, zero-hallucination data retrieval and real-time contextual boundary control to Large Language Models via Model Context Protocol (MCP) services or REST APIs.
*   **Numerical OOD (World Models & Edge Telemetry):** Provides out-of-the-box scale-invariant, cross-domain numerical precision for physical World Models, embedded microcontrollers, and real-time control systems via native C++ binaries, MCP, or cloud endpoints.

## SECTION 3: BILL OF MATERIALS AND HARDWARE INFRASTRUCTURE

**PROCUREMENT SPECIFICATION AND ENGINEERING REQUIREMENTS**
**PROJECT TITLE:** Sovereign AGI Cluster (Phase 1)
**TARGET TOPOLOGY:** 6-Node, 36-GPU Capable Symmetric Cluster

### 1. Project Scope
This document outlines the strict hardware, software, and configuration requirements for a 6-node compute cluster designed for extreme-scale machine learning. The system must be delivered fully assembled, pre-configured, and hydro-tested by the supplier.

All underlying infrastructure—power, memory, network, and hydraulics—must be fully provisioned on Day 1 to support the maximum theoretical expansion of 36 GPUs (Phase 3) without requiring chassis modifications, re-cabling, or fluid loop disassembly.

### 2. Hardware Bill of Materials (BOM)

**2.1 Compute Nodes**
Quantity: 6 Units
Each of the 6 nodes must be fully populated with maximum CPU and RAM bandwidth capabilities at the time of delivery.
*   **Chassis:** High-Density 4U Rackmount Server Chassis.
    *   Must support 6x PCIe 5.0 expansion slots without utilizing riser bottlenecks.
    *   Must include 4x 2000W 80+ Titanium Redundant Power Supplies per node.
*   **Motherboard:** ASUS Pro WS WRX90E-SAGE SE (EEB Form Factor). No substitutions permitted; specifically required for the 7x PCIe 5.0 x16 slots.
*   **CPU:** AMD Ryzen Threadripper PRO 7985WX (64-Core, 128 PCIe 5.0 lanes, 350W TDP).
*   **System RAM:** 1TB DDR5-5600 ECC RDIMM per node.
    *   Must be configured as 8x 128GB DIMMs to fully populate all 8 memory channels.
*   **OS Storage (Boot/Orchestration):** 2x 1TB M.2 NVMe PCIe 5.0 Enterprise SSDs per node.
    *   Pre-configured in hardware RAID 1.
*   **Data Storage (Model/Dataset):** 4x 7.68TB U.3 NVMe PCIe 5.0 Enterprise SSDs per node.
    *   Pre-configured in RAID 0 or ZFS.

**2.2 GPU Subsystem (Phase 1 Deliverable)**
Quantity: 12 Units (Distributed as 2 GPUs per node)
*   **GPU:** NVIDIA RTX 6000 Ada / Blackwell Server Edition (96GB GDDR7 VRAM per card).
*   **Form Factor / Cooling:** All cards must undergo OEM blower removal. Supplier must pre-install low-profile Direct-to-Chip (D2C) copper cold plates.

**2.3 Networking Fabric**
Data Plane must provide lossless RDMA over Converged Ethernet (RoCEv2).
*   **Node NIC:** 1x NVIDIA ConnectX-7 Dual-Port 400GbE per node. (Qty: 6 total).
*   **Top-of-Rack (ToR) Data Switch:** NVIDIA Spectrum-4 SN5000 Series Model SN5400 (SKU: 920-9N42C-00RB-7C0).
    *   2U Open Ethernet Switch, 64x QSFP56-DD ports, 25.6 Tbps switching capacity.
*   **Data Cables:** 400G QSFP-DD Direct Attach Copper (DAC) cables. (Qty: 6).
*   **Management Switch:** 1x 48-port 1GbE/10GbE managed switch (for IPMI, BMC, and Kubernetes control plane).

**2.4 Thermal Management & Fluid Dynamics**
Air cooling is prohibited for compute components. The system must utilize a Liquid-to-Liquid (L2L) architecture.
*   **Coolant Distribution Unit (CDU):** 1x 4U In-Rack Liquid-to-Liquid CDU.
    *   Must be rated for a minimum of 40kW of continuous heat rejection.
    *   Must feature redundant internal pumps and digital flow monitoring.
*   **Coolant Distribution Manifold (CDM):** 1x Vertical dual-pipe (Supply/Return) manifold mounted in the rear zero-U space.
*   **Quick-Disconnect (QDC) Infrastructure:** The manifold MUST feature pre-installed, blind-mate, dripless QDC valves for:
    *   6 CPU slots.
    *   36 independent GPU slots. (This is a hard requirement. The fluid loops for the future 24 GPUs must be plumbed and valved on Day 1 to ensure zero-downtime, plug-and-play scaling in Phases 2 and 3).

**2.5 Rack & Power Infrastructure**
Quantity: 1 Rack
*   **Server Rack:** 1x 42U Heavy-Duty Rack (Minimum 1200mm depth, 1,500kg dynamic load rating).
*   **Power Distribution Units (PDUs):** 2x 32A 400V 3-Phase Switched PDUs.
    *   Must support 22kW capacity per PDU (44kW total rack capacity).
*   **Peripherals:** 1x 1U KVM Console & Drawer.

### 3. Software Pre-Installation & Configuration
The supplier is responsible for bare-metal provisioning and base orchestrator validation prior to shipment.
*   **OS:** Ubuntu 24.04 LTS (or certified enterprise equivalent).
*   **Driver Layer:** Latest NVIDIA Datacenter Drivers, CUDA Toolkit, and NCCL libraries pre-installed.
*   **Network Configuration:** ConnectX-7 NICs must have RoCEv2 explicitly enabled and optimized at the firmware level.
*   **Containerization:** Kubernetes (K8s) pre-deployed across all 6 nodes.
*   **Orchestration:** KubeRay pre-installed and validated for dynamic multi-node actor scheduling.
*   **Validation Testing:** Supplier must execute a multi-node parallel workload test across the ToR switch to verify zero-packet-loss RDMA transport prior to crating.
